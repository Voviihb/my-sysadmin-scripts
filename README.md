# Учебный проект по системному администрированию

В репозитории представлен скрипт для мониторинга состояния сервера и конфигурация для его запуска в Docker

## Скрипт мониторинга

`script.sh` каждые 30 секунд записывает в `monitor.log` дату и время, состояние ОЗУ, использование дисков и загрузку системы. Скрипт работает до нажатия `Ctrl+C`.

## Запуск в Docker

Образ можно собрать и запустить через Docker Compose:

```bash
sudo docker compose up -d --build
```

Контейнер запускает скрипт мониторинга и HTTP-сервер на порту 8080. Проверка:

```bash
curl http://127.0.0.1:8080/monitor.log
```

## Nginx и systemd

Файл `nginx/my-app.conf` содержит конфигурацию Nginx. Файл `systemd/my-app.service` запускает контейнер после старта Docker при загрузке системы.
